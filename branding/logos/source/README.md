# VIGIL OS vector logo sources

The four shield/V paths are copied unchanged from branding/VIGILGLM/icon-color.svg,
which matches the geometry in branding/start.svg. Palette: blue #1763ef,
red #df3448, gold #edc652. No new icon geometry or embedded raster is used.
Transparent 80×80 icon bounds retain the original breathing room.
Wordmarks use exact display text VIGIL OS, with light/dark text variants and
transparent 320×80 bounds. Paths remain vector; text currently depends on
DejaVu Sans Bold. Before release, verify the approved font rendering or convert
wordmark text to outlines with licensing/provenance retained.

Raster derivatives are generated only during an approved disposable guest build.
They must preserve aspect ratio. Boot watermark output is 149×43, matching the
observed Fedora 44 spinner footprint, with transparent padding rather than stretch.
The raster shield/wordmark originals remain in vigil-lab/evidence/baseline-assets.
No derivatives have been rendered or tested in this static preparation step.
